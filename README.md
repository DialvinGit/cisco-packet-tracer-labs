# Cisco Packet Tracer Labs

Hands-on Cisco Packet Tracer networking labs featuring IPv4 subnetting, DHCP, VLAN segmentation, inter-VLAN routing, and dynamic OSPF failover.

## Labs Included
* **[Lab 01: SOHO-DHCP Network](./01-soho-dhcp-network)** — Small Office/Home Office network with automated IPv4 DHCP addressing and wired/wireless connectivity.
* **[Lab 02: Department VLANs](./02-department-vlans)** — Segmented enterprise network isolating five departments (VLANs 2–6) with 802.1Q trunking, Router-on-a-Stick inter-VLAN routing, and multi-pool IOS DHCP.
* **[Lab 03: 3-Router Triangle & OSPF Failover](./03-ospf-triangle-failover)** — Redundant full-mesh 3-router WAN connecting three LANs, testing static routing vs. dynamic OSPF automatic convergence during a link failure.
